# Peakseeker Expenditure Planner 🏔️

Peakseeker Expenditure Planner is a personal finance management tool designed to track everyday spending, manage budget categories, and monitor financial goals.

## Features
- Track daily income and expenses.
- Categorize spending (e.g., Food, Transport, Rent).
- View total balance and budget summaries.

## How to Run
1. Download or clone the project repository.
2. Open and run the main Python application script.
